ra1n IME 설치 및 삭제 안내

macOS용 두벌식 한글 입력기 · Apple Silicon · macOS 13 이상

⚠️ 설치 전에 먼저 읽어주세요

이 앱은 Apple 개발자 등록 없이 배포(ad-hoc 서명)됩니다. 그래서 설치할 때 “확인되지 않은 개발자” 경고가 뜰 수 있습니다. 이는 정상이며, 아래 설치 1단계의 우회 방법 중 하나로 진행하면 됩니다. 경고 자체를 없애려면 유료 개발자 등록이 필요하며, 현재 버전에는 적용돼 있지 않습니다.

설치

이 안내서와 함께 받은 ra1nIME.pkg로 설치합니다.

  1. 설치 실행 (경고가 뜨면 아래 방법 중 하나)

    방법 A — 우클릭 열기 (가장 간단)

    다운로드한 ra1nIME.pkg를 우클릭(control + 클릭) → 열기를 선택하고, 나타나는 대화상자에서 다시 열기를 누릅니다.

    방법 B — 시스템 설정에서 허용

    더블클릭해서 막혔다면 시스템 설정 → 개인정보 보호 및 보안으로 가서 맨 아래의 “확인 없이 열기” 버튼을 누릅니다.

    방법 C — 터미널 (경고 없이 바로 설치)

    sudo installer -pkg ~/Downloads/ra1nIME.pkg -target /

    Gatekeeper 대화상자를 거치지 않고 설치됩니다.

  2. 로그아웃 / 로그인 (또는 재부팅)
    입력기가 시스템에 정상 등록되려면 한 번의 재로그인이 필요합니다.
  3. 입력 소스 추가
    시스템 설정 → 키보드 → 입력 소스에서 ra1n IME를 추가합니다.
  4. 권한 설정 — 전역 한/영 토글이 동작하려면 두 권한이 필요합니다.

    손쉬운 사용 (Accessibility)

    설치 후 팝업이 자동으로 뜨고 목록에 추가됩니다. 체크박스만 활성화하면 됩니다.

    입력 모니터링 (Input Monitoring)

    ⚠️ 이 권한은 자동으로 추가되지 않습니다

    macOS 제한으로 목록에 자동 등록되지 않습니다. 아래 버튼으로 설정을 연 뒤, ＋ 버튼을 눌러 아래 경로의 앱을 추가하세요.

    🔓 입력 모니터링 설정 열기

    /Library/Input Methods/ra1nIME.app

    이 권한이 없으면 전역 한영 토글키가 동작하지 않습니다.

업데이트

새 버전의 ra1nIME.pkg를 위 설치 과정대로 다시 설치하면 됩니다.

⚠️ 업데이트할 때 주의

개발자 등록 없이 배포되므로, 매 업데이트마다 “입력 모니터링” 권한을 다시 허용해야 할 수 있습니다. 설치 후 알림이 뜨면 설치 4단계(권한 설정)를 다시 진행하세요.

삭제

아래 순서로 제거합니다.

  1. 입력 소스에서 제거
    시스템 설정 → 키보드 → 입력 소스에서 ra1n IME를 선택하고 － 버튼으로 제거합니다.
  2. 앱 삭제 — 터미널에서: 
    sudo rm -rf "/Library/Input Methods/ra1nIME.app"
  3. 설정·권한 정리 (선택) 
    defaults delete kr.ra1n.inputmethod.ra1nime
tccutil reset All kr.ra1n.inputmethod.ra1nime
killall cfprefsd TextInputMenuAgent
  4. 로그아웃 / 로그인으로 변경사항을 완전히 적용합니다.

💡 참고

권한 목록(입력 모니터링·손쉬운 사용)에 항목이 남아 있으면 시스템 설정 → 개인정보 보호 및 보안에서 수동으로 지울 수 있습니다.

문제 해결

증상확인
입력 소스 목록에 안 뜸로그아웃/로그인을 했는지 확인하세요.
한/영 토글이 안 됨“입력 모니터링” 권한이 켜져 있는지 확인하세요.
설치가 막힘설치 1단계의 방법 A~C 중 하나를 사용하세요.
